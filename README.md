# Projet : Prédiction des prix immobiliers (California Housing)
## 1. Problème Métier
L'agence immobilière souhaite automatiser l'estimation des prix pour gagner du temps et réduire les erreurs humaines.
## 2. Pourquoi le ML ?
Une règle simple est trop imprécise. Un modèle de Régression (Machine Learning) capturera les tendances complexes (revenus du 
quartier, localisation, etc.).
## 3. KPI (Indicateurs de Succès)
Le modèle doit obtenir une **MAE (Erreur Moyenne Absolue) inférieure à 0.40** (soit 40 000 $ d'erreur moyenne) pour être validé.
